# Smart Health Systems & Biomedical Sensors SDP 2026

Official website, schedule, and hands-on laboratory repository for the **Faculty & Student Development Programme (SDP) on Smart Health Systems & Biomedical Sensors** (17 Nov – 21 Nov 2026).

---

## 📅 Programme Overview
- **Dates**: 17 November – 21 November 2026
- **Timing**: 2:00 PM – 5:00 PM Daily
- **Format**: Hybrid / On-Campus Laboratory & Lectures
- **Focus**: Biomedical Signal Acquisition (ECG, EMG, EEG, PPG), Embedded Microcontrollers (Arduino Uno, ESP32), Real-time DSP & Filtering, Bluetooth Low Energy (BLE), and Cloud Telemetry (Firebase & Google Sheets).

---

## 🚀 Running Locally
You can view the site locally with any standard HTTP server:

```bash
# Python 3
python -m http.server 5500
```
Then navigate to `http://localhost:5500/` or `http://localhost:5500/smart_health_systems_sdp_2026.html`.
